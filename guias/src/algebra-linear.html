Álgebra Linear — a ideia geral

Uma matriz não é só uma tabela de números. É uma máquina que transforma vetores: estica, roda, reflete e achata o plano. Quase tudo neste guia (determinante, inversa, valores próprios) fica intuitivo quando se vê a matriz a deformar o espaço. Por isso começamos por aí.

O quadrado azul é o quadrado unitário; o paralelogramo vermelho é onde a matriz o leva. As colunas de $A$ são onde vão parar $e_1 = (1,0)$ e $e_2 = (0,1)$. Experimenta $b = c = 0$ (esticar), $a = d = 0,\ b = -1,\ c = 1$ (rodar 90°) ou $d = 0$ e $c = 0$ (achatar).

1. Matrizes e operações

Uma matriz $m \times n$ tem $m$ linhas e $n$ colunas. $a_{ij}$ é o elemento da linha $i$, coluna $j$.

Produto de matrizes$(AB)_{ij}$ = linha $i$ de $A$ "vezes" coluna $j$ de $B$ (multiplica-se elemento a elemento e soma-se). Só existe se o n.º de colunas de $A$ for igual ao n.º de linhas de $B$: $(m\times \mathbf{n})(\mathbf{n}\times p) = m\times p$.
Exemplo: $A = \begin{bmatrix}1&2\\3&4\end{bmatrix}$, $B = \begin{bmatrix}0&1\\1&0\end{bmatrix}$
Ver resolução

$AB = \begin{bmatrix}1\cdot0+2\cdot1 & 1\cdot1+2\cdot0\\ 3\cdot0+4\cdot1 & 3\cdot1+4\cdot0\end{bmatrix} = \begin{bmatrix}2&1\\4&3\end{bmatrix}$,   $BA = \begin{bmatrix}3&4\\1&2\end{bmatrix}$

$AB \neq BA$: o produto de matrizes não é comutativo. (Aqui, $B$ troca colunas quando multiplica à direita e troca linhas quando multiplica à esquerda.)

Propriedades a reter$(AB)^T = B^T A^T$ · $(AB)^{-1} = B^{-1}A^{-1}$ · $AI = IA = A$ · $AB = 0$ não implica $A = 0$ ou $B = 0$.
Experimenta Com $A$ de $2\times3$ e $B$ de $3\times 4$, qual é a dimensão de $AB$? E $BA$ existe?
Ver resposta$AB$ é $2\times 4$. $BA$ seria $(3\times4)(2\times3)$: 4 ≠ 2, por isso não existe.

2. Sistemas lineares e método de Gauss

Um sistema escreve-se como $AX = B$ e resolve-se na matriz ampliada $[A|B]$ com operações elementares sobre linhas, que não mudam as soluções:

  1. trocar duas linhas: $L_i \leftrightarrow L_j$;
  2. multiplicar uma linha por $k \neq 0$;
  3. somar a uma linha um múltiplo de outra: $L_i \leftarrow L_i + kL_j$.
Como fazer
  1. Escolhe o pivô (primeiro elemento ≠ 0) da 1.ª coluna.
  2. Anula tudo o que está abaixo dele.
  3. Passa à coluna seguinte, na linha seguinte, e repete até ficar em escada.
  4. Resolve de baixo para cima (substituição regressiva).
Exemplo: $\begin{cases}x+y+z=6\\2x-y+z=3\\x+2y-z=2\end{cases}$
Ver resolução

$\left[\begin{array}{ccc|c}1&1&1&6\\2&-1&1&3\\1&2&-1&2\end{array}\right] \xrightarrow[L_3 - L_1]{L_2 - 2L_1} \left[\begin{array}{ccc|c}1&1&1&6\\0&-3&-1&-9\\0&1&-2&-4\end{array}\right] \xrightarrow{L_3 + \frac13 L_2} \left[\begin{array}{ccc|c}1&1&1&6\\0&-3&-1&-9\\0&0&-\frac73&-7\end{array}\right]$

$z = 3$; $-3y - 3 = -9 \Rightarrow y = 2$; $x + 2 + 3 = 6 \Rightarrow x = 1$. Solução: $(1, 2, 3)$.

Ver no solver passo a passo
Experimenta Resolve $\begin{cases}2x + y = 5\\ 4x - y = 1\end{cases}$ por Gauss.
Ver resposta$L_2 - 2L_1$: $\left[\begin{array}{cc|c}2&1&5\\0&-3&-9\end{array}\right]$. $y = 3$, $x = 1$.

3. Característica e classificação de sistemas

Característica$\operatorname{car}(A)$ é o número de pivôs (linhas não nulas) depois de pôr a matriz em escada. Diz quantas equações são realmente "independentes".
Situação ($n$ = n.º de incógnitas)ClassificaçãoGeometria (3 incógnitas)
$\operatorname{car}(A) \neq \operatorname{car}(A|B)$Impossível (SI)os planos não têm ponto comum
$\operatorname{car}(A) = \operatorname{car}(A|B) = n$Possível e determinado (SPD)os planos cruzam-se num ponto
$\operatorname{car}(A) = \operatorname{car}(A|B) < n$Possível e indeterminado (SPI)reta ou plano de soluções

No SPI, o grau de indeterminação é $n - \operatorname{car}(A)$: o número de incógnitas livres.

Exemplo: $\begin{cases}x + y + z = 3\\2x + 2y + 2z = 6\end{cases}$
Ver resolução

$L_2 - 2L_1$ dá uma linha de zeros. $\operatorname{car}(A) = \operatorname{car}(A|B) = 1 < 3$: SPI com grau 2.

Soluções: $y = s,\ z = t,\ x = 3 - s - t$, com $s, t \in \mathbb{R}$. É um plano inteiro de soluções.

Experimenta Para que valor de $k$ é $\begin{cases}x + 2y = 1\\ 2x + ky = 3\end{cases}$ impossível?
Ver resposta$L_2 - 2L_1$: $(k-4)y = 1$. Com $k = 4$ fica $0 = 1$: SI. Com $k \neq 4$ é SPD.

4. Matriz inversa

Definição$A^{-1}$ é a matriz tal que $AA^{-1} = A^{-1}A = I$. Só existe se $A$ for quadrada e $\det A \neq 0$. Visualmente, $A^{-1}$ desfaz a deformação de $A$. Se $A$ achata o plano ($\det = 0$), não há forma de desfazer.
Como calcular
  1. 2×2: $\begin{bmatrix}a&b\\c&d\end{bmatrix}^{-1} = \dfrac{1}{ad - bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}$ (troca a diagonal, muda o sinal da outra e divide pelo determinante).
  2. n×n: escreve $[A\,|\,I]$ e faz Gauss-Jordan até chegar a $[I\,|\,A^{-1}]$.
Exemplo: $A = \begin{bmatrix}2&1\\5&3\end{bmatrix}$
Ver resolução

$\det A = 6 - 5 = 1$, logo $A^{-1} = \begin{bmatrix}3&-1\\-5&2\end{bmatrix}$. Verificação: $AA^{-1} = \begin{bmatrix}6-5 & -2+2\\15-15&-5+6\end{bmatrix} = I$ ✔

Aplicação: $AX = B \iff X = A^{-1}B$.

Experimenta Calcula a inversa de $\begin{bmatrix}4&2\\1&1\end{bmatrix}$ (depois confirma na CAS com [[4,2],[1,1]]^-1).
Ver resposta$\det = 2$, logo $\frac12\begin{bmatrix}1&-2\\-1&4\end{bmatrix} = \begin{bmatrix}\frac12&-1\\-\frac12&2\end{bmatrix}$.

5. Determinantes

$\det A$ é o fator pelo qual a matriz multiplica áreas (em 2D) ou volumes (em 3D). Se for negativo, a orientação inverte (como num espelho). Se for 0, o espaço é achatado e $A$ não tem inversa. Mexe na matriz no início deste guia e vê o determinante mudar.

Como calcular
  1. 2×2: $\begin{vmatrix}a&b\\c&d\end{vmatrix} = ad - bc$
  2. 3×3, regra de Sarrus: soma dos produtos das 3 diagonais "↘" menos a soma dos produtos das 3 diagonais "↙".
  3. Laplace: desenvolve por uma linha ou coluna com muitos zeros, com sinais em xadrez $\begin{smallmatrix}+&-&+\\-&+&-\\+&-&+\end{smallmatrix}$.
  4. Triangular: o determinante é o produto da diagonal. Por isso, em Gauss, $\det$ = produto dos pivôs, mudando o sinal a cada troca de linhas.
Exemplo: $\det\begin{bmatrix}1&2&3\\0&1&4\\5&6&0\end{bmatrix}$
Ver resolução

Pela 1.ª linha: $1\begin{vmatrix}1&4\\6&0\end{vmatrix} - 2\begin{vmatrix}0&4\\5&0\end{vmatrix} + 3\begin{vmatrix}0&1\\5&6\end{vmatrix} = 1(-24) - 2(-20) + 3(-5) = 1$

Propriedades$\det(AB) = \det A\det B$ · $\det(A^T) = \det A$ · $\det(A^{-1}) = \frac{1}{\det A}$ · $\det(kA) = k^n\det A$ · duas linhas iguais ⇒ $\det = 0$

6. Vetores: produto interno e produto externo

Produto interno (escalar)$u\cdot v = u_1v_1 + u_2v_2 + u_3v_3 = \|u\|\|v\|\cos\theta$
Dá um número. Se $u\cdot v = 0$, os vetores são perpendiculares.
$\|u\| = \sqrt{u\cdot u}$
Produto externo (vetorial), só em $\mathbb{R}^3$
$u\times v = (u_2v_3 - u_3v_2,\ u_3v_1 - u_1v_3,\ u_1v_2 - u_2v_1)$
Dá um vetor perpendicular a $u$ e a $v$; $\|u\times v\|$ = área do paralelogramo.
Exemplo: $u = (1,2,2)$, $v = (2,0,1)$
Ver resolução

$u\cdot v = 2 + 0 + 2 = 4$; $\|u\| = 3$, $\|v\| = \sqrt5$; $\cos\theta = \frac{4}{3\sqrt5} \approx 0{,}596$, logo $\theta \approx 53{,}4°$.

$u\times v = (2\cdot1 - 2\cdot0,\ 2\cdot2 - 1\cdot1,\ 1\cdot0 - 2\cdot2) = (2, 3, -4)$. Verificação: $(2,3,-4)\cdot u = 2 + 6 - 8 = 0$ ✔

Experimenta Para que $k$ são $(1, k, 2)$ e $(3, 1, -1)$ perpendiculares?
Ver resposta$3 + k - 2 = 0 \Rightarrow k = -1$.

7. Retas e planos no espaço

RetaPassa no ponto $P$ com direção $\vec v$:
$(x,y,z) = P + t\,\vec v,\ t \in \mathbb{R}$ (equação vetorial)
PlanoVetor normal $\vec n = (a,b,c)$, perpendicular ao plano:
$ax + by + cz = d$
Receitas
  1. Plano por 3 pontos $A, B, C$: $\vec n = \overrightarrow{AB}\times\overrightarrow{AC}$, e depois substitui $A$ para obter $d$.
  2. Distância de $P_0$ ao plano: $\dfrac{|ax_0 + by_0 + cz_0 - d|}{\|\vec n\|}$.
  3. Interseção reta–plano: substitui $(x,y,z) = P + t\vec v$ na equação do plano e resolve em $t$.
Exemplo: plano por $A(1,0,0)$, $B(0,1,0)$, $C(0,0,1)$
Ver resolução

$\overrightarrow{AB} = (-1,1,0)$, $\overrightarrow{AC} = (-1,0,1)$, $\vec n = (1\cdot1 - 0\cdot0,\ 0\cdot(-1) - (-1)\cdot1,\ (-1)\cdot0 - 1\cdot(-1)) = (1,1,1)$.

$x + y + z = d$; com $A$: $d = 1$. Plano: $x + y + z = 1$. Distância da origem: $\frac{|0 - 1|}{\sqrt3} = \frac{\sqrt3}{3}$.

8. Espaços vetoriais, bases e dimensão

Independência linear$v_1,\dots,v_k$ são linearmente independentes se $\alpha_1v_1 + \dots + \alpha_kv_k = 0$ só acontece com todos os $\alpha_i = 0$. Ou seja, nenhum é combinação dos outros.
Base e dimensãoUma base é um conjunto de vetores independentes que gera o espaço todo. A dimensão é o número de vetores de uma base: $\dim\mathbb{R}^n = n$.
Como testar
  1. Põe os vetores como colunas (ou linhas) de uma matriz.
  2. São independentes se $\operatorname{car} = $ número de vetores. Com $n$ vetores em $\mathbb{R}^n$, basta $\det \neq 0$.
Exemplo: $(1,0,1),\ (0,1,1),\ (1,1,0)$ formam uma base de $\mathbb{R}^3$?
Ver resolução

$\det\begin{bmatrix}1&0&1\\0&1&1\\1&1&0\end{bmatrix} = 1(0-1) - 0 + 1(0-1) = -2 \neq 0$. São independentes e são 3, portanto formam uma base.

Pelo contrário, $(1,2)$ e $(3,6)$ são dependentes: $(3,6) = 3(1,2)$. Estão na mesma reta e não geram o plano.

9. Valores e vetores próprios

Quase todos os vetores mudam de direção quando a matriz atua. Os vetores próprios são os especiais: só são esticados ou encolhidos, $A\vec v = \lambda\vec v$. O fator $\lambda$ é o valor próprio.

Passa o rato: quando $v$ está sobre uma reta verde, $Av$ fica na mesma reta.

Como calcular
  1. Polinómio característico: $\det(A - \lambda I) = 0$. As raízes são os valores próprios.
  2. Para cada $\lambda$, resolve $(A - \lambda I)\vec v = 0$. As soluções não nulas são os vetores próprios.
  3. Verificação rápida: soma dos $\lambda$ = traço (soma da diagonal) e produto dos $\lambda$ = $\det A$.
Exemplo: $A = \begin{bmatrix}2&1\\1&2\end{bmatrix}$
Ver resolução

$\det\begin{bmatrix}2-\lambda&1\\1&2-\lambda\end{bmatrix} = (2-\lambda)^2 - 1 = \lambda^2 - 4\lambda + 3 = 0 \Rightarrow \lambda = 1$ ou $\lambda = 3$.

$\lambda = 3$: $\begin{bmatrix}-1&1\\1&-1\end{bmatrix}\vec v = 0 \Rightarrow \vec v = (1,1)$.   $\lambda = 1$: $\begin{bmatrix}1&1\\1&1\end{bmatrix}\vec v = 0 \Rightarrow \vec v = (1,-1)$.

Verificação: $1 + 3 = 4$ = traço ✔; $1\cdot3 = 3 = \det A$ ✔. Confirma na CAS: eigVl([[2,1],[1,2]]).
