1. Polinómios e regra de Ruffini

Um polinómio é uma soma de termos $a\,x^n$ com $n$ natural, por exemplo $P(x) = 2x^3 - x + 5$. O grau é o maior expoente (aqui, 3).

Teorema do restoO resto da divisão de $P(x)$ por $(x - a)$ é $P(a)$. Logo, $a$ é raiz de $P$ se e só se $P(a) = 0$, e nesse caso $P(x) = (x-a)\,Q(x)$.
Como fatorizar um polinómio de grau 3
  1. Procura uma raiz entre os divisores do termo independente (experimenta $\pm1, \pm2, \pm3,\dots$).
  2. Divide por $(x - a)$ com a regra de Ruffini e obténs um polinómio de grau 2.
  3. Fatoriza o de grau 2 com a fórmula resolvente.
Exemplo: fatorizar $P(x) = x^3 - 6x^2 + 11x - 6$
Ver resolução

Divisores de $-6$: experimenta $x=1$: $P(1) = 1 - 6 + 11 - 6 = 0$ ✔. Ruffini por $(x-1)$:

Baixa-se o primeiro coeficiente; multiplica-se por 1 e soma-se à coluna seguinte; repete-se. Fica $Q(x) = x^2 - 5x + 6 = (x-2)(x-3)$.

Logo $P(x) = (x-1)(x-2)(x-3)$. As raízes são 1, 2 e 3, os pontos onde o gráfico corta o eixo dos $x$:

2. Inequações e quadros de sinal

Para resolver $\dfrac{A(x)}{B(x)} \geq 0$ (ou com produtos), não se "passa para o outro lado". Estuda-se o sinal de cada fator num quadro.

Como fazer
  1. Passa tudo para um membro: "… $\geq 0$".
  2. Fatoriza o numerador e o denominador.
  3. Encontra os zeros de cada fator e põe-nos por ordem na primeira linha do quadro.
  4. Preenche o sinal de cada fator em cada intervalo e multiplica os sinais.
  5. Os zeros do denominador nunca entram na solução.
Exemplo: $\dfrac{(x-1)(x+2)}{x-3} \geq 0$
Ver resolução

Solução: $x \in [-2, 1] \cup\ ]3, +\infty[$. O gráfico confirma: verde onde é positiva, vermelho onde é negativa.

Ver resposta$(x-2)(x+2) < 0$: parábola virada para cima com zeros $\pm 2$, negativa entre eles. $x \in\ ]-2, 2[$.

3. Módulo (valor absoluto)

Definição$|x| = \begin{cases} x & x \geq 0 \\ -x & x < 0 \end{cases}$. Geometricamente, $|x - a|$ é a distância entre $x$ e $a$ na reta real.

Pensar em distâncias resolve quase tudo:

  • $|x - a| < r$: "estar a menos de $r$ de $a$", ou seja, $a - r < x < a + r$.
  • $|x - a| > r$: "estar a mais de $r$ de $a$", ou seja, $x < a - r \ \lor\ x > a + r$.

Onde a reta vermelha está acima do "V", temos $|x-a| < r$.

Exemplo: $|2x - 3| \leq 5$
Ver resolução

$-5 \leq 2x - 3 \leq 5 \iff -2 \leq 2x \leq 8 \iff -1 \leq x \leq 4$. Solução: $[-1, 4]$.

Experimenta Resolve $|x + 1| > 3$.
Ver resposta$x + 1 < -3 \lor x + 1 > 3 \iff x < -4 \lor x > 2$.

4. Sucessões e progressões

Uma sucessão é uma função de domínio $\mathbb{N}$: $u_1, u_2, u_3, \dots$ Por isso o gráfico são pontos soltos e não uma linha.

Progressão aritmética (PA)Soma-se sempre a mesma razão $r$.
$u_n = u_1 + (n-1)\,r$
$S_n = \dfrac{u_1 + u_n}{2}\cdot n$
Progressão geométrica (PG)Multiplica-se sempre pela mesma razão $r$.
$u_n = u_1 \cdot r^{\,n-1}$
$S_n = u_1 \cdot \dfrac{1 - r^n}{1 - r}$ ($r \neq 1$)

PG com $u_1 = 1$: mexe na razão. Os pontos azuis são os termos e os verdes as somas $S_n$. Com $|r| < 1$, as somas aproximam-se de $\frac{1}{1-r}$.

Exemplo: PA com $u_1 = 3$ e $r = 4$
Ver resolução

$u_n = 3 + 4(n-1) = 4n - 1$. $u_{10} = 39$, $S_{10} = \frac{3 + 39}{2}\cdot 10 = 210$.

Monotonia e limite

Uma sucessão é crescente se $u_{n+1} - u_n > 0$ para todo o $n$. Converge para $L$ se os termos ficam tão perto de $L$ quanto se queira. Um limite famoso:

$\displaystyle\lim_{n\to\infty}\left(1 + \frac1n\right)^n = e \approx 2{,}718$

Experimenta Numa PG, $u_1 = 2$ e $u_4 = 54$. Qual é a razão?
Ver resposta$u_4 = 2 r^3 = 54 \Rightarrow r^3 = 27 \Rightarrow r = 3$.

5. Trigonometria e círculo trigonométrico

No círculo de raio 1, um ângulo $\theta$ define um ponto. A abcissa desse ponto é $\cos\theta$ e a ordenada é $\operatorname{sen}\theta$. Por isso $\operatorname{sen}^2\theta + \cos^2\theta = 1$: é o teorema de Pitágoras dentro do círculo.

Gráficos: amplitude, período, deslocamento

Equações trigonométricas
  1. $\operatorname{sen} x = \operatorname{sen}\alpha \iff x = \alpha + 2k\pi \ \lor\ x = \pi - \alpha + 2k\pi$
  2. $\cos x = \cos\alpha \iff x = \pm\alpha + 2k\pi$
  3. $\operatorname{tg} x = \operatorname{tg}\alpha \iff x = \alpha + k\pi$, com $k \in \mathbb{Z}$
Exemplo: $2\operatorname{sen}x = 1$ em $[0, 2\pi]$

$\operatorname{sen}x = \frac12 = \operatorname{sen}\frac{\pi}{6}$, logo $x = \frac{\pi}{6} + 2k\pi \lor x = \frac{5\pi}{6} + 2k\pi$. Em $[0,2\pi]$: $x = \frac{\pi}{6}$ ou $x = \frac{5\pi}{6}$.

Experimenta Resolve $\cos x = -\frac{\sqrt2}{2}$ em $[0, 2\pi]$.
Ver resposta$\cos x = \cos\frac{3\pi}{4}$: $x = \frac{3\pi}{4}$ ou $x = \frac{5\pi}{4}$.

6. Exponenciais e logaritmos

O logaritmo responde à pergunta "a que expoente tenho de elevar $a$ para obter $y$?": $\log_a y = x \iff a^x = y$. Por isso $\log_a$ é a inversa de $a^x$, e os gráficos são reflexos na reta $y = x$.

ExponencialLogaritmo
$a^x a^y = a^{x+y}$$\log(xy) = \log x + \log y$
$\frac{a^x}{a^y} = a^{x-y}$$\log\frac{x}{y} = \log x - \log y$
$(a^x)^y = a^{xy}$$\log(x^p) = p \log x$
$a^0 = 1$$\log_a 1 = 0$, $\log_a a = 1$
Mudança de base: $\log_a x = \dfrac{\ln x}{\ln a}$
Equações
  1. Exponenciais: escreve os dois lados com a mesma base, $a^{f(x)} = a^{g(x)} \iff f(x) = g(x)$. Se não der, aplica $\ln$ aos dois lados.
  2. Logarítmicas: primeiro o domínio (argumentos $> 0$). Junta os logaritmos com as propriedades e depois $\log_a A = \log_a B \iff A = B$.
Exemplo: $\ln(x-1) + \ln(x+1) = \ln 3$
Ver resolução

Domínio: $x - 1 > 0 \land x + 1 > 0 \iff x > 1$.

$\ln\big((x-1)(x+1)\big) = \ln 3 \iff x^2 - 1 = 3 \iff x = \pm 2$. Pelo domínio, só $x = 2$.

Experimenta Resolve $3^{2x} = 27$ e $e^{x} = 5$.
Ver resposta$3^{2x} = 3^3 \Rightarrow x = \frac32$. $x = \ln 5 \approx 1{,}609$.

7. Limites e continuidade (introdução)

$\displaystyle\lim_{x\to a} f(x) = L$ quer dizer que, quando $x$ se aproxima de $a$, $f(x)$ aproxima-se de $L$. O que interessa é o que acontece perto de $a$, e não em $a$.

Em $f(x) = \dfrac{x^2-1}{x-1}$, o ponto $x=1$ não pertence ao domínio (bola vazia), mas o limite existe e vale 2:

Continuidade$f$ é contínua em $a$ se $\lim_{x\to a} f(x) = f(a)$. Ou seja, o gráfico desenha-se sem levantar o lápis.
Indeterminações mais comuns
  1. $\frac{0}{0}$ com polinómios: fatoriza e simplifica.
  2. $\frac{\infty}{\infty}$ em $x \to \pm\infty$: põe em evidência a maior potência, ou seja, compara os graus.
  3. $\infty - \infty$ com raízes: multiplica pelo conjugado.
Exemplo: $\displaystyle\lim_{x\to+\infty}\frac{2x^2+1}{x^2-3}$
Ver resolução

Mesmo grau no numerador e no denominador, por isso o limite é o quociente dos coeficientes principais: $\frac{2}{1} = 2$.

8. Derivadas e estudo de funções

A derivada $f'(a)$ é o declive da reta tangente ao gráfico em $x = a$, ou seja, a taxa de variação instantânea. Passa o rato no gráfico e vê a tangente:

$\frac{u}{v}$$\frac{u'v - uv'}{v^2}$$f(g(x))$$f'(g(x))\cdot g'(x)$
Estudar monotonia e extremos
  1. Calcula $f'(x)$.
  2. Resolve $f'(x) = 0$.
  3. Faz o quadro de sinal de $f'$: com $f' > 0$ a função cresce ↗, com $f' < 0$ decresce ↘.
  4. Onde $f'$ muda de + para − há um máximo; de − para + há um mínimo.
Exemplo: $f(x) = x^3 - 3x$
Ver resolução

$f'(x) = 3x^2 - 3 = 3(x-1)(x+1) = 0 \iff x = \pm 1$.

$f' > 0$ em $]-\infty,-1[$ e $]1,+\infty[$, onde $f$ cresce. $f' < 0$ em $]-1,1[$, onde $f$ decresce.

Máximo relativo $f(-1) = 2$; mínimo relativo $f(1) = -2$.

Derivada passo a passo

A segunda derivada diz a concavidade: com $f'' > 0$ é virada para cima ∪ e com $f'' < 0$ para baixo ∩. Mais no guia de Cálculo 1.

9. Números complexos

$i$ é o número com $i^2 = -1$. Um complexo $z = a + bi$ é um ponto do plano $(a, b)$, também visto como vetor. A parte real fica no eixo horizontal e a imaginária no vertical.

Somar complexos é somar vetores, pela regra do paralelogramo. Aqui $u = u_1 + u_2 i$ e $v = v_1 + v_2 i$:

Forma algébrica$z = a + bi$
conjugado $\bar z = a - bi$
módulo $|z| = \sqrt{a^2 + b^2}$
Forma trigonométrica$z = |z|\,e^{i\theta} = |z|(\cos\theta + i\operatorname{sen}\theta)$
$\theta = \arg z$, o ângulo com o eixo real
Multiplicar é rodar e esticar$z_1 z_2$ tem módulo $|z_1||z_2|$ e argumento $\theta_1 + \theta_2$. Por isso multiplicar por $i$ (módulo 1, argumento $\frac{\pi}{2}$) roda 90°. Fórmula de De Moivre: $z^n = |z|^n e^{i n\theta}$.
Exemplos
Ver resolução

$(3+4i)(1-2i) = 3 - 6i + 4i - 8i^2 = 3 - 2i + 8 = 11 - 2i$

$\dfrac{1+i}{1-i} = \dfrac{(1+i)(1+i)}{(1-i)(1+i)} = \dfrac{2i}{2} = i$ (multiplica-se pelo conjugado do denominador)

$(1+i)^8$: $|1+i| = \sqrt2$, $\arg = \frac{\pi}{4}$, logo $(\sqrt2)^8 e^{i\,2\pi} = 16$.

Experimenta Escreve $z = -2 + 2i$ na forma trigonométrica.
Ver resposta$|z| = \sqrt{8} = 2\sqrt2$, está no 2.º quadrante, logo $\theta = \frac{3\pi}{4}$. $z = 2\sqrt2\, e^{i 3\pi/4}$.

Regra de LaplaceSe os casos são todos igualmente prováveis: $P(A) = \dfrac{\text{casos favoráveis}}{\text{casos possíveis}}$.
Probabilidade condicionada: $P(A|B) = \dfrac{P(A\cap B)}{P(B)}$. $A$ e $B$ são independentes se $P(A\cap B) = P(A)P(B)$.

Binómio de Newton e triângulo de Pascal

$(a+b)^n = \sum_{k=0}^{n}\binom{n}{k}a^{n-k}b^k$. Os coeficientes são uma linha do triângulo de Pascal: $(a+b)^4 = a^4 + 4a^3b + 6a^2b^2 + 4ab^3 + b^4$.
